# zarin.world — Portfolio Website

A personal portfolio for Zarin Roushan: a little world of ideas, experiments, and things I've built.

## Stack

- Next.js 15 + React 19
- TypeScript
- Tailwind CSS 4
- Framer Motion
- Lucide icons

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Keyboard shortcuts

- `H` — Home
- `W` — Selected work
- `A` — About
- `C` — Contact
- `?` — Open shortcuts
- `Esc` — Close shortcuts

## Before publishing

- Verify each project URL and replace any placeholder links.
- Add a real contact email address.
- Confirm social profile URLs.
- Update the project descriptions and technology tags to match each repository.
- Add a custom domain in your Vercel project when ready.
